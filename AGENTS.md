# Notes for coding agents

The person you're working with will walk an interviewer through this work, including how they
directed you. Help them keep a record:

- Keep `PROMPTS.md` at the repo root. For each request from the person, append the time, their
  request verbatim, and a line or two on what you did. Note anything you got wrong or they
  corrected.
- Never edit or condense earlier entries.
- Commit it along with the rest of the work.
